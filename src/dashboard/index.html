Controls against the NDPA 2023

What the gateway does for each principle, on every request.

Data minimisation

BVN, NIN, phone, account, card, email and names are tokenised. GPS and addresses are reduced to a district such as Lagos/Ikeja.

Storage limitation

The token vault lives for one request. The cache stores only redacted text. Zero-retention tenants are never stored.

Security

Hashed keys, per-tenant limits and budgets, jailbreak filtering in five languages, and no client IP or headers sent upstream.

Accountability

A content-free audit trail that can be verified, exported as a report for NDPC, NITDA and CBN.

Sovereignty

Runs on Nigerian infrastructure in front of a self-hosted N-ATLAS, so personal data never needs to leave the country.
